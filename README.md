## Normes de treball
- La branca principal serà `main`.
- Cada funcionalitat es desenvoluparà en una branca nova.
- Les branques es nomenaran amb el format `feature/nom-funcionalitat`.
- Els commits han de ser breus i descriptius.
- Cada branca modificarà també aquest README.
- Els canvis s'integraran a `main` mitjançant Pull Request.
- Cada Pull Request haurà de ser revisat per un altre membre del grup.
